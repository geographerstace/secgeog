Module 1: Automa Browser Automation

Perfect for: Repetitive downloads from portals like Taidii

💡 What is Automa?

Automa is a free, low-code/no-code browser extension (works on Chrome, Edge, and Firefox) that records and replays steps. You tell it what buttons to click, what text to select, and in what order, and it mimics your movements instantly.

🛠️ How to construct your flow with Gemini:

You don't need to struggle with complex configurations. Let Gemini set it up. Try pasting this setup request into Gemini:

Setup Prompt I will use Automa. Can you walk me through how to set up Automa for my use case of downloading multiple files from a portal?

🔒 Security Guidelines

  • Local Executions Only: Automa runs strictly in your computer's browser cache. It never uploads student or attendance profiles to cloud databases.
  • Pre-Target Restraints: Configure the extension so it *only* runs on specific secure URLs (e.g., your designated portal domain).
  • No Hardcoded Passwords: Log in manually *before* starting the Automa flow. Never code passwords into automation paths!

💡 Running into Errors? (AI Debugging Paradigm)

If Automa stops mid-run or throws a selector error, screenshot it and use this prompt template to let Gemini diagnose it:

# COPY & PASTE TO GEMINI

(Upload screenshot of error or copy error text)

Look at this screenshot / I got this error message "..." from Automa.

Can you tell me what this error means, how to find it in my workflow blocks, and walk me through step-by-step how to correct it?

Module 2: Microsoft Power Automate

Perfect for: Auto-sending emails to Principals & cross-app tracking

💡 What is Power Automate?

Power Automate is a core tool included in our organization's education M365 license. It tracks activities (such as a cell modifying in a KPI spreadsheet or a new file dropping into a folder) and triggers subsequent operations (sending alert emails or creating planner tasks).

🎓 Example KPI Use Case:

1. Trigger

KPI File is uploaded/updated

→

2. Action

Verify zero attendance lines

→

3. Output

Automated notification goes out

🔒 Enterprise Compliance

Because Power Automate operates natively inside our organization's M365 boundary, it is enterprise-compliant. However:

  • Ensure flows only connect to authorized corporate services (Teams, Outlook, SharePoint).
  • Do not configure flows to send restricted organizational KPI summaries to personal personal mailboxes.

Module 3: Visual Basic for Applications (Vibe Coding)

Perfect for: Instant Excel formatting, calculations & worksheet merging

Important Notice: To execute custom VBA scripts on your work-issued devices, you might need to coordinate an upgrade to the M365 Premium suite. Ask your Department or Pillar Head to route a service ticket to our internal Management Information Systems (MIS) team.

🕺 What is "Vibe Coding"?

Vibe coding means you don't write syntax manually! Instead, you write out the explicit formatting rules in plain English. Gemini generates the VBA script. You paste it directly into Excel's Developer Tab and run it. Your spreadsheet automates itself instantly.

📝 Master Vibe Coding Prompt Template (Slide 10)

I have 57 centre attendance files in a folder on my laptop. Each file is named <centre name>_May attendance.xlsx. Code a VBA for me to do the following, then walk me through how to implement the code. 1. Extract the "All" tab from each file in the folder and place it in a masterfile. 2. Rename each of the "All" tabs in the masterfile according to the centre's name. 3. Find the merged column named "Total Attendance". If the value is 0, highlight the entire row in yellow. I use a company laptop that runs on Windows, with a free education M365 license.

Module 4: Google Apps Script (GAS)

Perfect for: Automating Google Drive sheets & publishing dashboards

💡 What is Google Apps Script?

Google Apps Script is Google’s browser-native alternative to Excel’s VBA. It is highly capable, requiring no setup, and lives under "Extensions > Apps Script" inside any Google Sheet.

🛑 Best Practice: Guarding Against Excess AI Code Edits (Slide 13)

When working on custom tools or user interfaces, AI can sometimes over-rewrite code blocks that already work. Make sure your team uses this guardrail sequence when editing:

# STEP 1: Restrict AI to UX design rules

"Imagine you are the best UX/UI designer in the world. Give me recommendations on how you would redesign this webpage."

# STEP 2: Retain execution control

"Let me choose the recommendations I want and confirm them with me before making any changes."

# STEP 3: Pin target edits precisely

"Execute only the changes described above. Do not change any other code."

🔒 Apps Script Permissions

When deploying custom Google scripts:

  • Always restrict permissions so that the custom script can only read/write data in that specific file container.
  • Advise colleagues never to grant authorization to generic third-party scripts that require general access to their Google Drive account.
